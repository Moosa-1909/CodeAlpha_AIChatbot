# --- Java syntax and control flow ---
What is a for loop? | A for loop repeats a block a known number of times: for (int i = 0; i < n; i++) { ... }. Initialization, condition and update all sit in one line.
What is a while loop and a do while loop? | A while loop checks its condition first and may run zero times: while (cond) { ... }. A do-while runs the body once before checking the condition: do { ... } while (cond);
What is the enhanced for loop for each? | The enhanced for loop iterates over arrays and collections without an index: for (String s : list) { ... }
What is the difference between break and continue? | break exits the loop completely, while continue skips the rest of the current iteration and moves on to the next one.
What is an if else statement? | if-else runs code conditionally: if (cond) { ... } else if (cond2) { ... } else { ... }
What is a switch statement? | switch picks one branch based on a value (int, char, String or enum). Use break to stop fall-through into the next case, and default for unmatched values.
What is an array? | An array is a fixed-size, indexed collection of elements of one type, for example int[] a = new int[5]. Indexes start at 0.
What is the difference between String and StringBuilder? | String is immutable, so every change creates a new object. StringBuilder is mutable and faster for repeated changes, such as building text inside a loop.
What is a constructor? | A constructor is a special method with the class name and no return type. It initializes a new object when you call new.
What is the difference between overloading and overriding? | Overloading is the same method name with different parameters in one class (resolved at compile time). Overriding is a subclass redefining a parent method with the same signature (resolved at runtime).
What is the static keyword? | static members belong to the class rather than to any object, so they are shared and usable without creating an instance, like Math.max().
What is the final keyword? | final makes a variable a constant, stops a method from being overridden, and stops a class from being extended.
What is the this keyword? | this refers to the current object. Use it to reach its fields and methods, or to tell a field apart from a parameter with the same name.
What are the Java data types? | Primitive types are byte, short, int, long, float, double, char and boolean. Everything else, like String and arrays, is a reference type.
What is the Java Collections Framework? | A set of interfaces and classes for storing groups of objects: List (ArrayList), Set (HashSet), Queue and Map (HashMap).
